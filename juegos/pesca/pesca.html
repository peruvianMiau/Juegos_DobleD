Aventura de Pesca 🎣

Puntos: 0
Tiempo: 60s
Capturas: 0

¡Tiempo Agotado! 🐟

Puntuación Final: 0

Controles: Haz Clic Izquierdo en el agua para lanzar el anzuelo. Mantén presionado Clic para recoger la línea.

📜 Reglas del Juego

• Objetivo: Atrapa el mayor número posible de peces antes de que se agoten los 60 segundos.

• Lanzamiento: Haz clic izquierdo en cualquier punto del agua para arrojar el anzuelo.

• Recoger Línea: Mantén presionado el clic izquierdo para izar el sedal cuando un pez toque el anzuelo.

• Peces Dorados / Rápidos: Conceden mayor puntuación que los peces lentos superficiales.
